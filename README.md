# Himanshu Kumar Thakur — Portfolio

A modern, interactive personal portfolio built with React.  
Features multi-theme support, a live chalkboard, project showcases with live demos, and a code-editor style about section.

**Live Demo:** (https://my-portfolio-wine-six-15.vercel.app/)

---

## Features

- **Multi-theme system** — 4 beautiful themes (Cyber Dark, Midnight, Clean Light, Warm Cream)
- **Interactive Blackboard** — Visitors can draw, doodle, or leave messages (with undo/redo & color palette)
- **Project Showcase** — Clickable cards with Live Demo + GitHub links
- **Code Editor style About panel**
- Fully responsive design
- Smooth animations & interactive background
- Contact form that opens a pre-filled email

---

## Tech Stack

- **Frontend:** React 18
- **Styling:** Tailwind CSS + Custom CSS (CSS Variables for theming)
- **Icons:** Lucide React
- **Deployment:** Vercel
